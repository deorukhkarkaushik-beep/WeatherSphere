# 🌦️ WeatherSphere AI

### Intelligent Weather Forecasting & Climate Analytics Dashboard

WeatherSphere AI is an interactive weather forecasting application built using Python and Streamlit. It provides live weather information, forecast visualization, weather analytics and air-quality monitoring.

## 🚀 Features

- 🌍 Search weather for cities worldwide
- 🌤️ Live weather information
- 📅 16-day weather forecast
- 🌧️ Dynamic weather photographs
- ❄️ Rainy, sunny, cloudy and winter weather visualization
- 📊 Interactive weather analytics
- ⏰ Hourly weather forecasts
- 🌫️ Air quality monitoring
- 🗺️ Global weather map
- 🎨 Animated dashboard interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- Requests
- Open-Meteo API

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/deorukhkarkaushik-beep/WeatherSphere.git
```

**2. Open the project folder**

```bash
cd WeatherSphere
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run app.py
```

## 🌐 Weather Data Source

Weather information is retrieved using Open-Meteo APIs.
